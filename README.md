# Course2Career-Ai
Our project Course2Career is an AI-powered job portal designed to bridge the gap between education and employment. Today, most job seekers—especially students and fresh graduates—struggle to find jobs relevant to their degree or courses because traditional job portals rely mainly on keyword matching. This often leads to irrelevant job suggestions.

To solve this, our platform uses:

1. AI-based Resume Parsing
   Extracts structured information like skills, experience, education, and projects from resumes using models like LayoutLM.

2. AI-based Semantic Job Matching
   Uses BERT embeddings and Elasticsearch vector search to match candidates to jobs based on conceptual similarity, not keywords.

3. Real-time Chat System
   Allows direct communication between job seekers and recruiters using WebSockets.

4. Recruiter Dashboard
   Helps recruiters shortlist candidates, view analytics, and manage job postings.

5. Application Tracking System
   Gives students real-time updates about their application status.

6. Secure Authentication (JWT, OAuth)
   Keeps the platform protected.

Overall, the system combines AI, full-stack development, databases, microservices architecture, and real-time communication to provide a complete recruitment solution.

How to run the code:
1. Download zip file
2. Extract the files
3. Open code in any editor
4. Open the terminal, run the command "npm init -y"
5. Then run "npm run dev"
